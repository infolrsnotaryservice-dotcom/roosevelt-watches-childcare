ROOSEVELT WATCHES CHILD CARE — EDITABLE WEBSITE

FILES:
- index.html: all page text and sections (Home, Services, About Us, About Me, Questions)
- styles.css: colors, fonts, layout
- site-config.js: email, phone, hours, and form endpoint
- script.js: menu and question form behavior
- logo.png: last sunshine logo

HOW TO EDIT:
1. Unzip the folder.
2. Open index.html in a browser to preview.
3. Edit index.html in any text editor (or VS Code) to change wording.
4. Edit site-config.js to change contact details.
5. Upload all files together to Netlify, GitHub Pages, or another static host.

IMPORTANT ABOUT THE QUESTION BOX:
It works immediately by opening the visitor's email app with their message filled in.
To send messages directly without opening an email app, create a Formspree form
and paste its endpoint into formEndpoint in site-config.js.
Do not collect sensitive child or health details via the basic contact form.
