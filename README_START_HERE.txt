ROOSEVELT WATCHES — CLICK-TO-EDIT WEBSITE
1. Unzip this folder.
2. Open index.html in Chrome, Safari or another browser.
3. Click any highlighted wording on the page and type your changes.
4. Use Change Logo to select a new image. Use Accent to change the purple accent.
5. Save Draft stores changes in that browser (on that device).
6. Download Edited Page downloads a new index.html with your changes.
7. REPLACE the old index.html in this folder with the downloaded one before uploading the folder to Netlify or GitHub Pages. Keep styles.css, script.js and site-config.js with it.

The website's original design and sections are preserved. The brand at top now says Roosevelt Watches Child Care and the founder's name is Toniyah Garcia.
The question form opens the visitor's email app unless you configure Formspree in site-config.js.
